co_former and ccc are Matthew Plummer-Fernandez’s tools for reshaping and colouring 3D meshes, developed through the Digital Natives project, initiated in 2012. This browser restoration brings their working Processing versions into a two-stage workspace.

Launch co_former → ccc

Get the source

Download the source code and sample models (ZIP). The browser application is released under the MIT licence. The archive includes instructions for running it locally, tests and preserved Processing reference files.

Using the tools

  1. Reshape a sample or your own STL, OBJ, GLB or glTF in co_former.
  2. Choose Continue to colouring to carry the mesh into ccc.
  3. Export a GLB for a compatible 3D viewer, or save a session to continue later.

Models are processed in your browser. Switching stages keeps separate drafts locally; downloaded sessions are the durable save option. The code licence does not change the rights in models you upload.

For glTF, select any companion .bin files alongside the model. Imports retain geometry and base/vertex colours as face colours; textures are omitted and animations become static meshes. Use uncompressed files.

Credits & restoration

Original tools and artwork: Matthew Plummer-Fernandez. The Processing versions used HE_Mesh by Frederik Vanhoutte, toxiclibs and ControlP5. The browser version uses p5.js, distributed separately under LGPL 2.1. GLB/glTF import uses Three.js under MIT.

Historical Java dependencies and an adapted third-party OBJ reader remain local-only and are excluded from this release. The browser application runs without them. Read the porting notes and full credits and licensing details.
